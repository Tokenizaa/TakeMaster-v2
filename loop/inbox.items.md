# Loop Inbox Items

Este arquivo contém os itens de entrada (inbox) para o Loop Engineering.

Formato:
- ID
- Descrição
- Prioridade
- Status (pendente, em_progresso, concluído)
- Data de criação
- Data de atualização

Exemplo:
- [ ] item-001: Definir critérios de sucesso para G0
  - Prioridade: alta
  - Status: pendente
  - Criado: 2026-10-03
  - Atualizado: 2026-10-03
